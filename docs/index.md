## Design Principles

<div class="grid cards" markdown>

-   __Clarity over breadth__

    The core path stays intentionally narrow so the reader does not have to fight through an oversized survey before touching real methods.

-   __Notebook-native workflow__

    The website mirrors the actual repository structure, so the public site and the working lab stay aligned instead of drifting apart.

-   __Honest maturity__

    Runnable pages, scaffolds, and frontier notes are not mixed together. The site makes the current state of the project legible at a glance.

-   __Research-forward pacing__

    Readers can enter at foundations, jump to operator models, or scan frontier directions without losing the overall logic of the lab.

</div>
